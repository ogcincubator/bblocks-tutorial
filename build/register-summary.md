# OGC Building Blocks tutorial examples repository

A set of building blocks introducing capabilities, as a sequence of exercises.


Follow the instructions in the "About section" of each building block, starting with the [Orientation](bblock/ogc.bbr.tutorial.exercise0) exercise.


## Building Blocks

### `ogc.bbr.tutorial.exercise0` — 00 - Orientation

**Type:** schema

Orientation on the structure of Building Blocks

### `ogc.bbr.tutorial.exercise1` — 01 - JSON schema

**Type:** schema

Provide and validate an example JSON file.  Shows how the examples management component works and introduces a basic JSON schema.  (Note that building blocks may documented other forms of specification, however JSON schemas support semantic interoperability using available standard approaches and OpenAPI applications, and will be featured in these tutorials.)

### `ogc.bbr.tutorial.exercise10` — 10 - RDF BB

**Type:** model

A building block defining a building block for a data model described in ontology standards OWL and SHACL.  Such a building block allows logical constraints to be inherited by multiple implementation schemas using semantic annotations (such as JSON-LD)

### `ogc.bbr.tutorial.exercise11` — 11 - Profiling an Ontology

**Type:** model

Often data models and schemas are re-used with specific constraints - i.e. as a profile. This example shows how using building blocks allows inheritance of rules from a base ontology and addition of such constraints using SHACL.
